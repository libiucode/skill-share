# 科研论文叙事

把研究组织成可检验的论证：重要问题 → 现有解释或方法的具体缺口 → 有依据的洞察 → 针对洞察的方法 → 能区分竞争解释的证据 → 适用边界。叙事服务研究，不为已有结果虚构动机、机制或贡献。

## 先判断任务与证据成熟度

利用用户已有材料，确认任务、目标读者、当前主流做法、研究发现、方法与已有实验。只问会改变研究定位的关键缺失信息；其余用明确标注的假设推进。

- 构思阶段：输出待检验的故事假设和实验需求，不能写成已获证实的发现。
- 有方法或初步结果：区分观察、解释与因果假设；识别目前能成立的最强主张。
- 有完整结果：围绕证据组织论文，保留负结果、限制和竞争解释。
- 修改现稿：先诊断断裂的论证环节，再按用户要求改写；不擅自改成另一项研究。

用户指定语言、篇幅和章节时遵从；未指定时用中文做诊断，正文沿用原稿语言。不给每次任务都附加完整分析报告。

## 选择一条主线

按证据匹配下列范式，可以用另一条辅助，但不把六种全部塞进一篇论文。若材料不支持任何强叙事，采用清晰的增量改进叙事，具体交代收益和代价。

| 范式 | 适合的研究发现 | 必须回答的质疑 |
|---|---|---|
| 根因定位 | 现有方法出现稳定失效，研究定位了可干预的机制 | 是原因还是相关性？通过受控干预、竞争解释对照、预测验证支持机制；证据不足时称假设 |
| 反直觉重构 | 一个常见设定在明确条件下不必要或有害，替代方案有效 | 默认设定真的普遍吗？采用公平对照，说明反例范围及替代方案代价 |
| 理论解释经验 | 形式化结论解释已观察现象或导出新预测 | 假设是否成立？区分定理覆盖范围与经验外推，验证相关预测 |
| 新基准揭示失效 | 现有评测遗漏重要能力，新的测量揭示系统性缺口 | 基准是否有效？检查构念、泄漏、难度与混杂，证明失败与真实任务有关 |
| 社会价值 | 方法解决特定人群或真实场景的实际瓶颈 | 谁受益、怎样受益？报告部署条件、成本和群体差异；代理指标不等于已实现社会影响 |
| 极简统一 | 同一原则或接口覆盖此前分散的任务 | 统一是否只是命名？在多任务及匹配资源下验证收益、复杂度与必要组件 |

先用一句话定位：在【条件/任务】下，现有【做法/解释】留下【具体缺口】；本研究基于【洞察】，提出【方法/理论/评测】，通过【证据】支持【有边界的结论】。槽位用于思考，不原样塞进正文。

## 按请求产出

### 论文构思与定位

给出主线及选择理由、核心问题、可证伪假设、最小验证方案和停止条件。可提出有实质差异的候选定位，但按现有证据推荐一个。若结果可能来自规模、数据或训练预算，优先设计区分这些解释的对照。用户只给想法时，不虚构结果支持它。

### Introduction

用递进段落完成：具体场景及重要性 → 主流做法和精确缺口 → 关键观察及解释 → 方法如何回应缺口 → 结果和贡献。段数随篇幅调整。

开头尽快落到研究对象，避免泛泛的时代背景。缺口必须对应相关工作，不能把稻草人当主流。区分“尚未解决”与“在本研究设置中仍有不足”。方法出现之前，读者应已理解为什么需要它。没有结果时提供结构草稿并标出待补证据，不生成貌似真实的数值。

### 贡献表述

每条写清研究新增了什么、相对于什么、由什么支持。区别发现、理论、方法和评测贡献；数量随实际内容变化。已有研究定位下的一项改进也可以是有效贡献。数据集、代码公开仅在确有产物或明确计划时写出对应状态。“首次”“普适”“解决根因”等强词需要相应证据；不以获奖或录用承诺替代研究价值。

### 实验论证

按主张设计实验，而非按已有表格拼故事。给出紧凑证据矩阵：

| 主张 | 最有区分力的实验/证明 | 对照与混杂因素 | 观察指标 | 什么结果会削弱主张 | 当前状态 |
|---|---|---|---|---|---|

按相关性选择公平基线、受控消融、机制干预、泛化、失败案例、成本与不确定性。消融提升只能说明组件在当前设置下有用，不能独自证明根因。主指标提升不自动支持可靠性、泛化或部署价值。区分已完成、需补做和无法支持的主张；不要求每项研究机械完成所有实验类型。

### 现稿诊断

优先定位问题定义不清、动机与方法脱节、主张超出证据、竞争解释未排除、贡献重复以及边界遗漏。输出具体位置、理由和替换文本或补证方案。只有用户要求整体重写时才重写全文。

## 交付前核对

- 读者能否复述问题、洞察、方法为何必要及证据如何支持结论？
- 每项核心主张是否对应真实证据，观察与因果是否区分？
- 相关工作、指标、引文与奖项是否有来源？未提供的引用不编造，标注需要查证；需要外部资料时再检索。
- 表达强度是否匹配证据，有无把局部结果写成普遍结论？
- 是否存在可削弱故事的结果与明确适用边界？
